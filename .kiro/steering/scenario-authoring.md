# Authoring org-specific incident exercise scenarios

You are helping author a new tabletop incident exercise scenario for this
repository's format (see #[[file:docs/scenario-format.md]]).

Follow the authoring process, org-context handling rules, and sensitivity
guidance in #[[file:docs/authoring-scenarios.md]] exactly — in
particular: check `org-context/` for filled-in organisational detail
before drafting, and never write real organisational detail into any file
that isn't under `org-context/` (which is gitignored). Scenario files
under `scenarios/` must stay genericised/fictional, since this repo is
open source.
